Live Now

First up: Japanese

Type on your regular Dubeolsik keyboard, get real-time Hiragana. A statistical engine trained on a 4,153-word vocabulary, plus explicit grammar rules for particles and verb endings, fills in what a plain rulebook alone would miss.

  • Real-time conversion — Dubeolsik in, Hiragana out, no retraining needed
  • Statistically trained — a 4,153-word vocabulary plus explicit particle/conjugation grammar rules catch what character-level statistics alone miss
  • Manual override markers — ~ for long vowels, ^ for dakuten, for the cases statistics alone gets wrong

TRACK04

Setup

Up and running in 3 minutes

No App Store, so macOS needs a few extra steps to trust it. Do these once, in order.

1

Unzip

Double-click the downloaded file in your Downloads folder.

2

Run the installer

Open Terminal, drag the unzipped folder onto the window to jump there, then run:

terminal
bash install.sh
3

Log out, log back in

This is how macOS notices the new keyboard exists. A restart also works.

4

Add the input source

System Settings → Keyboard → Input Sources → Edit → +, find Japanese, add HangulJapaneseIME.

5

Switch and type

Click the input source icon in the menu bar, pick it, and type Dubeolsik like always.

Want it gone? Same folder, run bash uninstall.sh.

TRACK05

Fine control

When the engine guesses wrong, correct it

The engine is statistical, not a fixed rulebook — so it occasionally misses a long vowel or picks the unvoiced version of a consonant. Two markers let you override it, syllable by syllable, without retraining anything.

~

Long vowel (장음)

Attach right after a syllable to stretch its vowel sound.

도→ど
도~→どう
^

Dakuten (탁음)

Attach right after a syllable to force its voiced consonant (か→が, さ→ざ, た→だ, は→ば).

카→か
카^→が

Stack both on the same syllable: 카^~ → があ. Everything else in the sentence still goes through the trained engine as usual — markers only touch the syllable they're attached to.

TRACK06

One Script, Every Language

What's next?

Hangul has already proven it can go beyond Korean. In 2009, the Cia-Cia language of Buton Island, Indonesia — with no writing system of its own — adopted Hangul because it captured their sounds best. Hangulpia turns that experiment into a product.
